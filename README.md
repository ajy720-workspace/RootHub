# RootHub

RootHub is a PWA-style vocabulary learning app that decomposes English words into prefix/root/suffix and explains etymology.

## Stack
- Next.js (App Router, TypeScript)
- Tailwind CSS
- Supabase (Postgres/Auth)
- OpenAI API

## Quick Start
1. Install deps: `npm install`
2. Copy env: `cp .env.example .env.local`
3. Run dev server: `npm run dev`

## Current Scope
Phase 1 MVP: search -> analysis -> visualization -> DB caching.
